# 02 - Feature Roadmap

## Purpose

Defines feature priorities to prevent scope creep and random development.

---

## V1 (Launch MVP)

* Auth system
* User profile basics
* Application tracker CRUD
* Status pipeline
* Search / filters
* Dashboard summary
* Resume vault
* Reminder system
* Responsive UI

## V1.1 (Immediate Improvements)

* CSV export
* Better analytics charts
* Bulk actions
* Resume tagging improvements
* Interview notes section

## V2 (Growth Stage)

* DSA planner
* Study streaks
* AI resume tailoring
* Mock interview generator
* Company insights
* Notification center

## V3 (Expansion)

* Chrome extension for quick save jobs
* Referral network tools
* Placement cell dashboards
* Team accounts / colleges
* Mobile app

## Kill / Avoid List (for now)

* Social feed
* Random chat features
* Blockchain gimmicks
* Too many AI chatbots
* Marketplace complexity early

## Prioritization Rule

Build retention features before vanity features.
